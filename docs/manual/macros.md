# Macros

A macro is a saved sequence of presses, holds, releases and waits, played with one press.

## Making one

1. Open the setup's **Macros** tab, and click **+ New macro**.
2. Add steps: **Tap** (press and let go), **Hold down**, **Release**, **Wait**, or **Move stick**.
3. Each step can press a key or key combination, a mouse button, the scroll wheel, or a gamepad button.

For fighting games, **Insert motion…** adds a quarter circle, dragon punch or half circle, written for a character facing right.

## Playing one

- **Play once**: each press plays the whole macro, even if you let go early.
- **Repeat while held**: keeps looping while you hold the button, then stops straight away.

When a pass ends, anything the macro still holds is let go. To loop a macro without holding the button, wrap it in **Toggle**.

> **Tip:** renaming a macro updates every button that uses it.
