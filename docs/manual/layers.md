# Layers

A layer is a second set of mappings that applies only while you hold a button. For example, hold LB and the face buttons type F1 to F4, while the Right Stick scrolls. Or hold the aim button, and the mouse stick slows down. Anything the layer doesn't change keeps its normal mapping.

## Holding a layer

Choose **Hold layer…** as the action of any button, trigger, stick direction, zone, gesture or combo. The layer stays on while you hold that input, and goes off when you let go.

A layer can't be toggled on, and a menu item can't hold one. If a set of mappings should stay on until you switch back, make it a [mode](modes.md) instead.

## Layers or modes

Use a layer to extend or fine-tune the controls while a button is held: lean while LB is held, change the mouse response while aiming. Use a [mode](modes.md) for a different control scheme that you switch to and stay in, such as driving. Layers apply on top of whichever mode is on.

## Several at once

Layers can stack. If two of them disagree about a button, the one turned on most recently wins.

## Showing a layer

A layer can show its name on screen while it's on, show one of the setup's info overlays (such as a cheat sheet), or show nothing at all.

The [Guide overlay](guide-button.md)'s Mappings list each layer that a button holds in a section of its own, with what the layer changes.

## Editing

Layers are edited on the setup's **Layers** tab. A setting the layer doesn't change reads "Same as" the profile it's shown over, with an **Override** button. **Override** lets the layer set its own value, and **Back to base** removes that value again.
