# Sharing setups: packs and the library

A setup can be shared as a pack, a `.padpack` file. To make one, click **Export…** on the setup's **Details** tab. To use someone else's, click **+ Add setup**, then **Import a file…**.

## The library

**+ Add setup** lists the setups that come with Padwight, with games installed in Steam, Heroic or Lutris, and running games, first.

You can also add one from the game: when a game the library knows comes to the front, a note at the top of the screen says so. Tap Guide to see its profiles and add it. *Not now* asks again next time the game starts; *Never* stops asking for that game. The note only shows while a controller is connected.

## Importing

A preview shows what's in the pack, which controller features it needs, and any name clashes with your setups. Nothing changes until you press **Save & apply**.

## Updates

When a newer version of a pack or library setup is available, the sidebar marks it *update*. Before updating, Padwight lists the changes you've made since adding it, because the update replaces them.

> **Tip:** a pack made with a newer Padwight can't be imported. Update Padwight first.
