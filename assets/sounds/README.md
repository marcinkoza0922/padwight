# Bundled sound samples

Sampled cues for `SoundKind` (see `src/sound/library.rs`). Each is a mono 44.1 kHz 16-bit WAV, trimmed,
normalized and faded out from the original. All are CC0 (public domain); credit is not required.

| Files | Source |
|---|---|
| `bong`, `select`, `toggle`, `pluck`, `confirm`, `error`, `glitch` | Kenney, [Interface Sounds](https://kenney.nl/assets/interface-sounds) (CC0) |
| `rollover`, `switch` | Kenney, [UI Audio](https://kenney.nl/assets/ui-audio) (CC0) |
| `latch`, `page` | Kenney, [RPG Audio](https://kenney.nl/assets/rpg-audio) (CC0) |
| `wood`, `plate`, `tin`, `bell` | Kenney, [Impact Sounds](https://kenney.nl/assets/impact-sounds) (CC0) |
| `typewriter` | Cassie-OrbitGames, [Typewriter sounds](https://opengameart.org/content/typewriter-sounds) on OpenGameArt (CC0) |
| `geiger`, `nano`, `radio`, `heartbeat`, `casing`, `lockpick`, `shing`, `fault` | Synthesized for this app (CC0), first for the library packs |
| `sand`, `boing`, `shutter`, `zap`, `purr`, `clank`, `card` | Synthesized for this app (CC0) by `scripts/synth-sounds.py` |
