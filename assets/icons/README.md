# Built-in icons

The sixteen icons `{icon:name}` can draw without a pack carrying its own (see `src/icons.rs`). Each is
a 24-unit SVG drawn with `currentColor` strokes, so it takes the text's color.

Most are from [Lucide](https://lucide.dev) (ISC); `wheel` is from [Tabler Icons](https://tabler.io/icons)
(MIT). `pistol` and `rifle` are drawn for this app. Both licences need their notice kept with copies
of the icons, so the notices are in `LICENSES.txt` beside them.
