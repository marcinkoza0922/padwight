# Tutorial: the Guide button, the Mapping guide and the in-game menu

The Guide button (the Xbox, PlayStation or Home button) works the same in every game, and Padwight keeps it from the game and from Steam. You'll use the Guide overlay, write the notes and mapping guide it shows, and change settings while you play.

## 1. Open the Guide overlay

Tap Guide in a game. The overlay opens when you let go; tap again to close it.

![The Guide overlay: Notes on the left, the menu in the middle, and the Mappings with a layer's own section on the right](https://raw.githubusercontent.com/marcinkoza0922/padwight/main/docs/images/manual/guide-overlay.png "The Guide overlay.")

1. **Notes** (1): what the author of the setup wants you to know.
2. **The menu** (2): Quick Settings, Edit Controls, the on-screen keyboard and numpad, mouse mode, media controls, Switch Profile and, while Steam runs, the Steam overlay. Move with the D-pad or Left Stick, choose with A, close with B.
3. **Mappings** (3): what each input does in the current profile and mode. When the setup has [modes](Tutorial-Modes), press Left or Right to see the others.
4. **A layer's section** (4): each [layer](Tutorial-Layers) a button holds gets its own box.

**Shortcuts:** hold Guide and press X for the on-screen keyboard, Y for the numpad, LB for media controls, Start for the in-game menu, RB for a screenshot or L3 to start or stop a recording; or hold Select for two seconds to force-quit the focused window. With the overlay open, press the shortcut alone. Guide + Right Stick turns on **mouse mode**, where the controller drives the pointer; press Guide to leave it.

## 2. Write the notes and the mapping guide

Both belong to a profile, on its **Guide** tab.

![The Guide tab: the Notes text box and the Mapping guide's rows, each with its text, a Show checkbox and a Share with dropdown](https://raw.githubusercontent.com/marcinkoza0922/padwight/main/docs/images/manual/guide-tab.png "The Guide tab of the Deus Ex profile.")

1. **Guide notes** (1): what the controls don't make obvious, such as when to switch layers. Buttons in curly braces, such as `{south}`, show as glyphs, as the preview below shows.
2. The **Mapping guide** has a row for each input. Its text (2) is what the overlay's Mappings say; plain words such as "Use / pick up" read better than "Mouse right click". Left empty, it shows the default.
3. Untick **Show** (3) to hide a row. The mapping still works.
4. **Share with** (4) merges inputs into one row, such as both D-pad sides for "Lean". **Split** undoes it.
5. **+ Add a row** at the bottom adds a row of your own, for what the mappings don't show.

Press **Save & apply**, then tap Guide in the game to see it.

## 3. Move the shortcuts

Every shortcut above can be moved, which helps a controller with no Guide button. Open **App settings › Controller shortcuts**. It applies to every setup.

![The Controller shortcuts tab with the opener set to a combo and clashes marked](https://raw.githubusercontent.com/marcinkoza0922/padwight/main/docs/images/manual/shortcuts-tab.png "The Controller shortcuts tab. Here the opener is Select + Start.")

1. The tab shows a ⚠ (1) while something needs a look.
2. **Open the Guide overlay** (2): pick **Button**, **Double tap**, **Triple tap**, **Long press** or **Combo**, then the button, or press **Set by pressing** and press it on the controller. A combo takes up to four buttons (**+ Button**). **Off** is allowed, with a warning. If one of your profiles already uses that input, the row lists it, and a ⚠ marks the setup in the sidebar.
3. The Guide shortcuts and mouse mode's keys have the same choices (3).
4. A ⚠ line (4) names the other shortcut on the same input. Both save, but only one can work.
5. **Reset** (5) puts a shortcut back.
6. Further down, **Menu buttons** moves the buttons that choose and go back (to swap A and B, say), and the last groups move the media controls', numpad's and keyboard's own buttons.

The Guide button itself stays reserved: nothing else can be put on it.

## 4. Change controls while you play

Hold Guide and press Start (or choose it from the Guide menu) to open the in-game menu over the game.

![The in-game menu with Quick Settings and Edit Controls](https://raw.githubusercontent.com/marcinkoza0922/padwight/main/docs/images/manual/in-game-menu.png "The in-game menu.")

**Quick Settings** changes stick speeds, gyro sensitivity, Invert Y, deadzones, rumble, overlay size and the profile, and can turn remapping off if a mapping gets in the way. An aim layer or mode with its own speed gets its own row. Left and right change a number by about 10% (by half with RB held).

**Edit Controls** is the full editor for the game in front of you: buttons, sticks, gyro, combos, modes, layers, macros, menus and overlays. Changes apply at once and are saved when you save.

If no setup matches the window in front, your first change creates one for it, so you can fix a game's controls without leaving it.
